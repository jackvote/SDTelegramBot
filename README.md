Stable Diffusion Local Telegram Bot

Бот предназначен для управления локальной версией Stable Diffusion от AUTOMATIC1111, через Telegram.
Полезные рекомендации по установке в канале: https://t.me/automatic1111_useful
Бот использует API от AUTOMATIC для взаимодействия с SD и асинхронную библиотеку Aiogram, для взаимодействия с Telegram.

Функционал:
- Добавление и удаление пользователей и админов в файле .env
- В папке data в файле sd_config можно изменить стандартные настройки генерации, они используются при добавлении новых пользователей и админов, и при нажатии на кнопку Сброс настроек
- Возможность переключения моделей, а так же выбора нескольких стилей
- Подключение для генерации и отключение нескольких Lora (канал с большим количеством LoRa и ссылками на civitai.com: https://t.me/yes_ai_lora)
- Настройки генерации и seed сохраняются для каждого пользователя в базе данных
- Настройки, которые можно изменить: Negative prompt, Model, Styles, CFG Scale, Batch count, Sampler, Hires Fix
- Вывод текущих настроек
- Сброс настроек на стандартные, заданные в файле sd_config в папке settings
- Включение и отключение сохранения фото на ПК, в файле sd_config в папке settings, изменить значение переменной save_files на True чтобы включить и False выключить. В переменной output_folder можно указать свой путь для сохранения изображений.
- Запуск SD при старте бота. Можно включить и отключить в файле bot_config.
- Перезапуск SD с кнопки в меню Settings. Кнопка доступна только админам бота.
- Генерация изображений по промпту. При заданном чётном количестве изображений, генерация идёт в два потока.

Подготовка к запуску:
1. В файле "webui-user.bat", в строке set COMMANDLINE_ARGS добавить --api (set COMMANDLINE_ARGS=--args)
2. Запустить SD
3. В Телеграм найти BotFather, создать бота и скопировать Bot Token (инструкции по созданию telegram-ботов ищите на просторах интернета :)

Установка:
1. В интерфейсе Automatic1111 (SD) перейти на вкладку Extensions (Расширения) и в ней на Install from URL (Установка с сайта)
2. В поле "URL for extension's git repository" вставить адрес расширения: https://github.com/jackvote/SDTelegramBot и нажать кнопку Install
4. В папке с ботом создать файл .env и заполнить поля как в примере .env.dist
3. Перейти на вкладку Installed, отметить галочкой расширение SDTelegramBot и нажать кнопку "Apply and restart UI".
4. После перезапуска SD зайти в каталог расширений \extensions\SDTelegramBot
5. Запустить файл "start_bot.bat"
6. Если всё сделано правильно, то в Телеграм придет сообщение "Бот Запущен", тем ID, которые были указаны в env

## Список нововведений в форке

### 🖼️ Добавлен режим img2img
- Возможна загрузка картинки со сжатием (фото) и как файл без сжатия (документ) — файл сохраняет оригинальное разрешение.
- Можно указать степень изменения, поставив перед промптом коэффициент: `3:промпт` — это Denoising strength = 0.3. Принимаются и дробные значения (`2.5:промпт` = 0.25).

### 👥 Многопользовательский режим
- Полная изоляция данных пользователей: настройки, промпты и результаты одного пользователя никак не пересекаются с другими.
- У каждого пользователя свой комплект настроек генерации: модель, стили, LoRa, семплер, шаги, размер, CFG, количество картинок, HiRes-параметры, негативный промпт.

### 💾 Сохранение состояния
- Сохраняются не только настройки, но и текущие данные: последний промпт и базовый сид.
- Всё переживает перезапуск бота: старые кнопки в чате продолжают работать, а бот помнит, на чём вы остановились.
- Персональное уведомление при старте: пользователям с сохранённым промптом — «настройки сохранены, введите новый промпт или нажмите Повторить», новым — «введите промпт».

### 🖼️ Интерфейс чата
- Информация о генерации (промпт, модель, семплер, стили, LoRa, базовый сид) теперь прикреплена к самому фото, а не идёт отдельным сообщением.
- Панель управления (инлайн-кнопки) вынесена в отдельное сообщение и автоматически удаляется после нажатия «Повторить» / «Повторить с seed» — чат не загромождается.
- Мгновенный отклик кнопок: индикатор нажатия гаснет сразу, без «зависаний».
- Ошибки ввода в настройках (не число, выход за диапазон) показываются отдельным сообщением и не ломают открытое меню.
- Исправлена пагинация в выборе размеров изображений.

### 🎲 Работа с сидами
- В подписи пакета указывается базовый сид; сиды картинок внутри пакета инкрементируются (2-я = base+1, 3-я = base+2).
- «Повторить» — тот же промпт с новым случайным сидом.
- «Повторить с seed» — точное воспроизведение пакета с сохранённым базовым сидом.
- Ручное задание сида в формате `сид&промпт`: можно сделать базовым сид любой картинки из прошлого пакета (например, base+1), чтобы воспроизвести именно её.
- Сид и промпт сохраняются между перезапусками бота.

### ⏳ Очередь и прогресс
- Запросы пользователей не пересекаются: пока SD занята генерацией, новый запрос ставится в ожидание с индикатором «Очередь занята», а после освобождения приходит уведомление «Освободилось. Повторите запрос».
- Новый прогресс-бар с заголовком («🎨 Ваша генерация»), плавными и редкими обновлениями — без мельтешения и лишнего спама правками.
- Временные сбои связи больше не приводят к потере или дублированию генераций: бот пережидает их и продолжает работу сам.

### ⚙️ Параметры генерации по умолчанию
- 3 изображения за запрос вместо одного.
- Портретный формат 576×768 вместо квадратного 640×640.
- ADetailer по умолчанию отключён: расширение установлено не у всех, и его отсутствие больше не ломает генерацию.
- Более мягкий апскейл HiRes Fix (scale 1.5 вместо 2): на слабых картах могло не хватать памяти.
- Обновлён негативный промпт по умолчанию.
